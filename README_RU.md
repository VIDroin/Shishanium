# Шишаниум — NeoForge 1.21.1

Проект мода для Minecraft 1.21.1 и NeoForge 21.1.252. Требуется Java 21.

## Что делает блок
- Единственный добавленный блок — тёмно-зелёный стержнеобразный «Шишаниум».
- Блок доступен в отдельной вкладке творческого инвентаря; естественная генерация и лут сундуков не добавлены.
- В радиусе 50 блоков раз в полсекунды накладывает слепоту, замедление, усталость добычи и голод.
- Чтобы отключить ауру, блок должен быть полностью окружён шестью железными блоками: сверху, снизу и с четырёх сторон.

## Сборка
1. Установи JDK 21.
2. Открой папку проекта в IntelliJ IDEA или другом Gradle-совместимом редакторе.
3. Выполни `gradle build` (или `./gradlew build`, если добавишь Gradle Wrapper).
4. Готовый JAR появится в `build/libs/`.
5. Положи JAR в папку `mods` профиля Minecraft с NeoForge 21.1.252.

В проекте не включена функция урона от удара предметом в руке.

## Сборка без установки Gradle на компьютер (GitHub Actions)

В проект добавлен workflow `.github/workflows/build.yml`. Чтобы получить собранный JAR через облако:
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions**.
3. Выберите **Build Shishanium mod** и нажмите **Run workflow** (если сборка не запустилась автоматически).
4. Дождитесь завершения. Если сборка успешна, внизу страницы запуска появится артефакт **shishanium-jar** — скачайте его и распакуйте.

Если сборка завершилась ошибкой, откройте шаг **Build mod** и сохраните текст ошибки, чтобы можно было исправить проект.
